=====================================
🔥 FIREBASE STORAGE SETUP GUIDE
=====================================

Follow these steps to integrate Firebase Storage for inventory images:

=====================================
STEP 1: Install Required Packages
=====================================

Run this command in your backend directory:

npm install firebase-admin uuid

=====================================
STEP 2: Create Firebase Project
=====================================

1. Go to https://console.firebase.google.com/
2. Create a new Firebase project (or use existing one)
3. In Project Settings, note your project ID
4. Enable Firebase Storage:
   - Click "Storage" in the left sidebar
   - Click "Get Started"
   - Choose security rules (Start in test mode for development)
   - Click "Done"

=====================================
STEP 3: Get Service Account Key
=====================================

1. In Firebase Console, go to:
   Project Settings > Service Accounts
2. Click "Generate New Private Key"
3. Download the JSON file

=====================================
STEP 4: Configure Backend
=====================================

OPTION A: Use JSON File (Development)
---------------------------------------
1. Save the downloaded JSON file as:
   backend/config/serviceAccountKey.json
2. Add to your .env file:
   FIREBASE_STORAGE_BUCKET=your-project-id.appspot.com
3. The serviceAccountKey.json is already in .gitignore

OPTION B: Use Environment Variable (Production)
-----------------------------------------------
1. Copy the entire content of the JSON file
2. Add to your .env file:
   FIREBASE_SERVICE_ACCOUNT={"type":"service_account",...entire JSON content...}
   FIREBASE_STORAGE_BUCKET=your-project-id.appspot.com

=====================================
STEP 5: Update Firebase Storage Rules
=====================================

For production, update Firebase Storage rules in Firebase Console:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // Allow public read access
    match /{allPaths=**} {
      allow read: if true;
      allow write: if false; // Backend handles writes
    }
  }
}

=====================================
STEP 6: Test the Integration
=====================================

1. Start your backend server
2. Look for this message in the console:
   ✅ Firebase Admin initialized successfully
3. Try adding an inventory item with an image
4. Check Firebase Storage console to see the uploaded image

=====================================
TROUBLESHOOTING
=====================================

Error: "Firebase Admin initialization error"
- Check if FIREBASE_STORAGE_BUCKET is set correctly in .env
- Verify serviceAccountKey.json exists or FIREBASE_SERVICE_ACCOUNT is set
- Ensure the JSON file is valid

Error: "Failed to upload image to Firebase Storage"
- Check Firebase Storage is enabled in Firebase Console
- Verify storage rules allow write access from backend
- Check if the image is in valid base64 format

Error: "Permission denied"
- Update Firebase Storage security rules
- Make sure the service account has proper permissions

=====================================
HOW IT WORKS
=====================================

1. Frontend sends base64 image to backend (no changes needed)
2. Backend uploads base64 image to Firebase Storage
3. Firebase returns a public URL
4. Backend stores the URL in MongoDB (not the base64)
5. Frontend displays images using the Firebase URL

Benefits:
- Faster database queries (no large base64 strings)
- Better performance and scalability
- CDN-backed image delivery
- Reduced MongoDB storage costs
- Automatic image optimization possible
